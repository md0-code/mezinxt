@doc cuplor-disc | hardware | Cuplor de disc flexibil (FDA)
  Cuplorul ("Floppy Disk Adapter", {c}FDA{/}) este o placheta introdusa intr-un
  conector de extensie al placii de baza; leaga {c}1 - 4{/} unitati de disc
  flexibil de 5,25 inch sau 8 inch (nu amestecate), in simpla/dubla
  densitate (FM/MFM). La citire regenereaza datele cu o bucla PLL analogica,
  la scriere foloseste precompensare. Controlorul este {c}NEC uPD 765{/} (I8272).

  {h}Conectori de iesire{/}

   {c}26 contacte{/}  cablu plat          {c}»{/} doua unitati din interiorul blocului
   {c}25 contacte{/}  mama, panoul spate  {c}»{/} toate cele patru unitati

  Deci: 2 interioare + 2 exterioare, sau 4 exterioare ([[interfata-disc|interfata discului]]).
  Datele se transfera prin {b}DMA{/} (canalul 2), sfirsitul unei operatii prin
  intrerupere (nivelul 6): [[intreruperi-dma|intreruperi si DMA]].

  {h}Porturile cuplorului{/}

   {b}3F2{/}  {c}iesire{/}          registrul de iesire (motoare, selectie, initializare)
   {b}3F4{/}  {c}citire{/}          registrul de stare al FDC
   {b}3F5{/}  {c}citire/scriere{/}  registrul de date al FDC: date, comenzi, parametri,
   {/}     {/}                informatii de stare

  {h}Registrul de iesire{/}  {d}adresa 3F2H, numai scriere; RESET il pune pe 0{/}

     {b}  7   {/} {b}  6   {/} {b}  5   {/} {b}  4   {/} {b}  3   {/} {b}  2   {/} {b}  1   {/} {b}  0   {/}
    {d}┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐{/}
    {d}│{/} mot3 {d}│{/} mot2 {d}│{/} mot1 {d}│{/} mot0 {d}│{/} DMA  {d}│{/} FDC  {d}│{/} US1  {d}│{/} US0  {d}│{/}
    {d}└──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘{/}
     {d}└───────{/} motoarele {d}───────┘{/}
   {c}FS0, FS1{/}  selectia unitatii, daca e pornita:
              {c}00{/} = 0 (A)   {c}01{/} = 1 (B)   {c}10{/} = 2 (C)   {c}11{/} = 3 (D)
   {c}FS2{/}       initializare FDC: initializat cind bitul e 0; se activeaza
              trecindu-l in 1 prin program
   {c}FS3{/}       valideaza cererile de DMA si intrerupere catre magistrala
              (la 0 sint blocate)
   {c}FS4 - FS7{/} motoarele unitatilor 0 - 3 (semnalele MOTOR ON 0-3); la 0
              motorul e inactiv si unitatea nu poate fi selectata

  {h}Registrul de stare al FDC{/}  {d}adresa 3F4H, numai citire{/}

     {b}  7   {/} {b}  6   {/} {b}  5   {/} {b}  4   {/} {b}  3   {/} {b}  2   {/} {b}  1   {/} {b}  0   {/}
    {d}┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐{/}
    {d}│{/} RQM  {d}│{/} DIO  {d}│{/} NDM  {d}│{/}  CB  {d}│{/} DDB  {d}│{/} DCB  {d}│{/} DBB  {d}│{/} DAB  {d}│{/}
    {d}└──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘{/}
   {c}DB0 - DB3{/}  {b}DAB, DBB, DCB, DDB{/}: unitatea A, B, C, D ocupata, in
              mod cautare pista ("seek")
   {c}DB4{/}  {b}CB{/}   FDC ocupat: o comanda de citire/scriere este in curs
   {c}DB5{/}  {b}NDM{/}  FDC este in mod non DMA
   {c}DB6{/}  {b}DIO{/}  directia transferului: {c}1{/} de la registrul de date al FDC
              spre microprocesor; {c}0{/} invers
   {c}DB7{/}  {b}RQM{/}  registrul de date este pregatit sa trimita/primeasca
              date; DIO si RQM se folosesc impreuna pentru protocolul

@doc comenzi-disc | hardware | Comenzile controlorului de disc
  Controlorul NEC uPD 765 (I8272) executa {c}15{/} comenzi. Fiecare are trei faze:

  {d}┌──────────────────────┐ ┌────────────┐ ┌──────────────────────────┐{/}
  {d}│{/} {b}1 COMANDA{/}            {d}│ │{/} {b}2 EXECUTIE{/} {d}│ │{/} {b}3 REZULTAT{/}               {d}│{/}
  {d}│{/} FDC primeste de la   {d}│ │{/} FDC executa{d}│ │{/} informatii de stare si   {d}│{/}
  {d}│{/} procesor informatiile{d}│ │{/} operatia   {d}│ │{/} de gestiune sint         {d}│{/}
  {d}│{/} necesare operatiei   {d}│ │{/}            {d}│ │{/} pregatite pentru procesor{d}│{/}
  {d}└──────────────────────┘ └────────────┘ └──────────────────────────┘{/}

  Comanda si rezultatul sint transferuri pe mai multi octeti prin registrul
  de date (3F5H); starea transferului se citeste din 3F4H ([[cuplor-disc|cuplorul de disc]]).
  Primul octet al comenzii, in binar:

  {h}Citire si scriere{/}  {d}comanda: cod, HD US1 US0, parametri{/}

   {c}MT MF SK 0 0 1 1 0{/}  {b}Citeste date{/} {d}(Read Data){/}
   {c}MT MF SK 0 1 1 0 0{/}  {b}Citeste date sterse{/} {d}(Read Deleted Data){/}
   {c}MT MF 0  0 0 1 0 1{/}  {b}Scrie date{/} {d}(Write Data){/}
   {c}MT MF 0  0 1 0 0 1{/}  {b}Scrie date sterse{/} {d}(Write Deleted Data){/}
   {c}0  MF SK 0 0 0 1 0{/}  {b}Citeste o pista{/} {d}(Read a Track){/}
   {c}0  MF 0  0 1 0 1 0{/}  {b}Citeste ID{/} {d}(Read ID){/}
   {c}0  MF 0  0 1 1 1 1{/}  {b}Formateaza o pista{/} {d}(Format a Track){/}

  Octetul 2: {c}X X X X X HD US1 US0{/}. Parametrii urmeaza, apoi executia:
   {c}C H R N EOT GPL DTL{/}  citire/scriere ({b}Read a Track{/}: C H R EOT GPL DTL)
   {c}N SC GPL D{/}  formatare: FDC formateaza un cilindru intreg
  Executia: transfer de date intre FDD si sistem; {b}Read a Track{/} citeste tot
  cilindrul de la index pina la EOT; {b}Read ID{/} memoreaza prima informatie
  corecta din cilindru. Rezultat: {c}ST0 ST1 ST2 C H R N{/}.

  {h}Comparare{/}  {d}comanda ca la citire; executia compara datele{/}

   {c}MT MF SK 1 0 0 0 1{/}  {b}Comparare egala{/} {d}(Scan Equal){/}
   {c}MT MF SK 1 1 0 0 1{/}  {b}Mai mica sau egala{/} {d}(Scan Low or Equal){/}
   {c}MT MF SK 1 1 1 0 1{/}  {b}Mai mare sau egala{/} {d}(Scan High or Equal){/}
  Parametri si rezultat ca la citire ({c}C H R N EOT GPL DTL{/}; {c}ST0..ST2 C H R N{/}).

  {h}Pozitionare si stare{/}

   {c}0 0 0 0 0 1 1 1{/}  {b}Recalibrare{/} {d}(Recalibrate){/}
   {/}                 octetul 2: {c}X X X X X 0 US1 US0{/}; capul se pozitioneaza pe
   {/}                 pista 0; fara rezultat
   {c}0 0 0 0 1 1 1 1{/}  {b}Cautare pista{/} {d}(Seek){/}
   {/}                 octetul 2: {c}X X X X X HD US1 US0{/}, apoi {c}NCN{/}; capul ajunge
   {/}                 pe cilindrul cerut; fara rezultat
   {c}0 0 0 0 0 0 1 1{/}  {b}Specificare{/} {d}(Specify){/}
   {/}                 octetii {c}SRT HUT{/} si {c}HLT ND{/}; fara rezultat
   {c}0 0 0 0 1 0 0 0{/}  {b}Stare intrerupere{/} {d}(Sense Interrupt Status){/}
   {/}                 rezultat {c}ST0 PCN{/} (la sfirsitul cautarii pistei)
   {c}0 0 0 0 0 1 0 0{/}  {b}Stare unitate{/} {d}(Sense Drive Status){/}
   {/}                 octetul 2: {c}X X X X X HD US1 US0{/}; rezultat {c}ST3{/}
   {r}coduri invalide{/}  {b}Invalid{/}: controlorul intra in stare de
   {/}                 asteptare; rezultat {c}ST0 = 80{/}

@doc disc-stare | hardware | Registrele ST0-ST3 si simbolurile discului
  La sfirsitul unei comenzi, in faza de rezultat, se citesc registrele de
  stare {c}ST0 - ST3{/}; ele nu se confunda cu registrul de stare (3F4H) si se
  citesc numai dupa o comanda, referindu-se doar la ea.

  {h}ST0{/}
     {b}  7  {/} {b}  6  {/} {b}  5  {/} {b}  4  {/} {b}  3  {/} {b}  2  {/} {b}  1  {/} {b}  0  {/}
    {d}┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐{/}
    {d}│{/} IC  {d}│{/} IC  {d}│{/} SE  {d}│{/} EC  {d}│{/} NR  {d}│{/} HD  {d}│{/} US1 {d}│{/} US0 {d}│{/}
    {d}└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘{/}
   {c}D7 D6{/}  cod de intrerupere: {c}00{/} terminare normala (NT); {c}01{/} terminare
          anormala (AT), executia a inceput dar nu s-a finalizat corect;
          {c}10{/} comanda invalida (IC), nu va fi lansata; {c}11{/} terminare
          anormala: semnalul READY al FDD si-a schimbat starea
   {c}D5 SE{/}  sfirsit cautare ("Seek End"): 1 cind FDC executa comanda
   {c}D4 EC{/}  verificare echipament: eroare de la FDD sau pista 0 nu apare
          dupa 77 de impulsuri (recalibrare)
   {c}D3 NR{/}  neoperational: FDD "not ready" la o comanda de citire/scriere,
          sau comanda pe a doua fata a unui disc cu o singura fata
   {c}D2 HD{/}  adresa capului la intrerupere     {c}D1 D0{/}  unitatea ({c}US1 US0{/})

  {h}ST1{/}
     {b}  7  {/} {b}  6  {/} {b}  5  {/} {b}  4  {/} {b}  3  {/} {b}  2  {/} {b}  1  {/} {b}  0  {/}
    {d}┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐{/}
    {d}│{/} EN  {d}│{/}  0  {d}│{/} DE  {d}│{/} OR  {d}│{/}  0  {d}│{/} ND  {d}│{/} NW  {d}│{/} MA  {d}│{/}
    {d}└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘{/}
   {c}D7 EN{/}  sfirsit de cilindru: acces la un sector dincolo de sfirsit
   {c}D6, D3{/} neutilizate, intotdeauna 0
   {c}D5 DE{/}  eroare de date: eroare CRC in cimpul ID sau in cel de date
   {c}D4 OR{/}  depasire ("Over Run"): FDC nu a fost servit la timp
   {c}D2 ND{/}  date lipsa: sectorul nu e gasit (citire, scriere date sterse,
          scanare); cimpul ID nu se poate citi (Read ID); sectorul de
          inceput nu e gasit (citirea unui cilindru)
   {c}D1 NW{/}  scriere nepermisa: semnal de protectie la scriere de la FDD
   {c}D0 MA{/}  lipsa marca de adresa ID (si pune in 1 bitul MD)

  {h}ST2{/}
     {b}  7  {/} {b}  6  {/} {b}  5  {/} {b}  4  {/} {b}  3  {/} {b}  2  {/} {b}  1  {/} {b}  0  {/}
    {d}┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐{/}
    {d}│{/}  0  {d}│{/} CM  {d}│{/} DD  {d}│{/} WC  {d}│{/} SH  {d}│{/} SN  {d}│{/} BC  {d}│{/} MD  {d}│{/}
    {d}└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘{/}
   {c}D7{/}  nefolosit, intotdeauna 0
   {c}D6 CM{/}  control marca adresa: sector cu adresa stearsa
   {c}D5 DD{/}  eroare de date (CRC) in cimpul de date
   {c}D4 WC{/}  cilindru eronat: C de pe discheta difera de cel din registrul ID
   {c}D3 SH{/}  la scanare, conditia "egal" este satisfacuta
   {c}D2 SN{/}  scanare necorespunzatoare: FDC nu gaseste un sector
   {c}D1 BC{/}  cilindru necorespunzator: C difera de registrul ID si C = FF
   {c}D0 MD{/}  lipsa marca de adresa in cimpul de date

  {h}ST3{/}  {d}reflecta semnalele unitatii{/}
     {b}  7  {/} {b}  6  {/} {b}  5  {/} {b}  4  {/} {b}  3  {/} {b}  2  {/} {b}  1  {/} {b}  0  {/}
    {d}┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐{/}
    {d}│{/} FT  {d}│{/} WP  {d}│{/} RDY {d}│{/} T0  {d}│{/} TS  {d}│{/} HD  {d}│{/} US1 {d}│{/} US0 {d}│{/}
    {d}└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘{/}
   {c}D7{/} FAULT   {c}D6{/} WRITE PROTECT   {c}D5{/} READY   {c}D4{/} TRACK 0   {c}D3{/} TWO SIDE
   {c}D2{/} SIDE SELECT   {c}D1 D0{/} SELECT 1, SELECT 0

  {h}Simbolurile comenzilor{/}

   {c}C{/}        numar cilindru
   {c}D{/}        octet de umplere (paterne de date scrise intr-un sector)
   {c}DTL{/}      lungimea datelor citite/scrise intr-un sector, cind N = 00
   {c}EOT{/}      numarul ultimului sector al unui cilindru
   {c}GPL{/}      lungimea GAP 3 intre sectoare
   {c}H{/}        adresa capului (0 sau 1) din cimpul ID;  {c}HDS{/} selectia capului
   {c}HLT{/}      timp de incarcare a capului: 2 - 254 ms, cuante de 2 ms
   {c}HUT{/}      timp de descarcare a capului: 16 - 240 ms, cuante de 16 ms
   {c}MF{/}       0 simpla densitate, 1 dubla densitate
   {c}MT{/}       multipista: un cilindru pe ambele fete (HD0 si HD1)
   {c}N{/}        numar de octeti de date dintr-un sector
   {c}NCN{/}      numarul noului cilindru, in urma unei cautari de pista
   {c}ND{/}       mod nou DMA
   {c}PCN{/}      cilindrul actual al capului, rezultat al Sense Interrupt Status
   {c}R{/}        numarul sectorului de citit sau scris;  {c}R/W{/} citire/scriere
   {c}SC{/}       sectoare pe cilindru
   {c}SK{/}       omite (sare peste) marca de adresa a datelor sterse
   {c}SRT{/}      rata pasului motorului: 1 - 16 ms, cuante de 1 ms, aceeasi
   {/}         pentru toate unitatile
   {c}STP{/}      la scanare: 1 compara sectoarele contigue octet cu octet,
   {/}         2 sectoarele alternate
   {c}US0 US1{/}  selectia unitatii (0 sau 1)

  JUNIOR-XT lucreaza cu {c}1 - 4{/} unitati de disc flexibil, de 5,25 inch sau de
  8 inch; {r}nu se pot folosi simultan{/} unitati de ambele marimi.

   {a:3F} 5,25 inch {/}                               {a:3F} 8 inch {/}
   simpla sau dubla fata                     numai simpla fata
   40 / 80 piste pe fata                     77 de piste
   numai dubla densitate (MFM)               numai dubla densitate (MFM)
   2 in blocul logic, alimentate din sursa;  exterioare, cu surse proprii:
   exterioare: subansamblul UDF-201          subansamblul UDF-102A
   {d}fabricate de IEPER{/}                        {d}fabricate de IEPER{/}

  {h}5,25 inch{/}  {d}in interiorul blocului logic{/}

  Alimentate din [[sursa|sursa de alimentare]]: {c}+5 V{/} pentru logica si {c}+12 V{/} pentru
  amplificatoare, motorul pas cu pas si antrenarea dischetei. Comanda: cablu
  plat cu 26 de fire de la conectorul de 26 contacte al cuplorului.
