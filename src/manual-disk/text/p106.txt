{b}PUSHF{/b} = Salvare indicatoare
-----------------
|1 0 0 1 1 1 0 0|
-----------------

{b}POPF{/b} = Restaurare indicatoare
-----------------
|1 0 0 1 1 1 0 1|
-----------------

{b}ADD{/b} = Adunare
Registru/memorie cu registru
----------------------------------
|0 0 0 0 0  0 d w | mod  reg  r/m|
----------------------------------

Imediat la registru/acumlator
----------------------------------------------------------------
|1 0 0 0 0 0 s w | mod  0 0 0  r/m  | date | date daca s:w = 01|
----------------------------------------------------------------

Imediat la acumulator
------------------------------------------
|0 0 0 0 0 1 0 w | date | date daca w = 1|
------------------------------------------

{b}ADC{/b} = Adunare cu transport
Registru/memorie si registru la oricare
---------------------------------
|0 0 0 1 0 0 d w | mod  reg  r/m|
---------------------------------

Imediat la registru/memorie
---------------------------------------------------------------
|1 0 0 0 0 0 s w | mod  0 1 0  r/m | date | date daca s:w = 01|
---------------------------------------------------------------

{b}INC{/b} = Incrementare
Registru/memorie
---------------------------------
|1 1 1 1 1 1 1 w | mod  reg  r/m|
---------------------------------

Registru
----------------
|0 1 0 0 0  reg|
----------------

{b}AAA{/b} = Ajustare ASCII pentru adunare
-----------------
|0 0 1 1 0 1 1 1|
-----------------
